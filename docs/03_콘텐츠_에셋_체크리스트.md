## 2. 텍스트 (config.py `CLINIC` 에 입력)

- 병원 정식 명칭 / 짧은 이름 / 영문 표기
- 대표 전화, 팩스
- 도로명 주소 (층 포함), 시/군/구, 우편번호
- 대표자 성명, 사업자등록번호
- 대표원장 성명 · 약력 → `_macros.html` doctor_section 의 "원장님 이력이 들어갈 자리입니다." 박스를 실제 이력 목록으로 교체
- 진료시간 (평일·점심·토요일), 휴진일, 주차 안내
- 지역명 (SEO 용, 예: "○○시 ○○동")
- 블로그 URL (있으면)
- 문의 접수 메일 주소 (있으면)

## 3. 키·계정

- 카카오 개발자 JavaScript 키 (`KAKAO_JS_KEY`) + 병원 위도/경도 (`CLINIC_LAT`, `CLINIC_LNG`)
- 네이버 서치어드바이저 사이트 소유확인 메타값 (`NAVER_SITE_VERIFICATION`)
- 도메인 (있으면) → `SITE_URL`
