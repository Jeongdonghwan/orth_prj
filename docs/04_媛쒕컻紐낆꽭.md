# 04. 개발 명세 — 클로드코드 Phase 지시서

각 Phase 시작 시 클로드코드에 `CLAUDE.md` + 해당 Phase 블록만 붙여 넣는다. Phase 완료 → 스크린샷 확인 → 다음 Phase.

---

## Phase 1 — 뼈대 + 메인
**목표**: `python run.py` 실행 시 `/`에서 prototype/index.html과 동일한 화면.

1. `app/__init__.py` create_app(): Flask, config 로드, blueprint 등록, `@app.context_processor`로 `clinic` dict(이름·전화·주소·시간) 전 템플릿 주입 → 병원 정보는 `config.py` `CLINIC = {...}` 한 곳에서만 관리.
2. `base.html`: prototype의 `<head>`, 헤더, 퀵메뉴, 모바일 하단 바, 푸터 분리. `{% block content %}`.
3. `index.html`: prototype 본문 9개 섹션을 그대로 옮김. 하드코딩 텍스트는 그대로 두되 병원명·전화·주소·시간은 `{{ clinic.* }}`.
4. `static/css/style.css`, `static/js/main.js` 분리. 탭·슬라이드·헤더 고정 로직 동작 확인.
5. placeholder 이미지는 `static/img/`에 회색 더미(1600×900) 생성해 두기 (Pillow 스크립트 `scripts/make_placeholders.py`).
6. 확인: 데스크톱 1440 / 태블릿 768 / 모바일 375 스크린샷 3장.

## Phase 2 — 서브페이지
1. `about.html` `doctor.html` `clinic.html` `location.html` — 기획서 5장 구조대로. 메인 섹션 매크로화(`templates/_macros.html`: clinic_tabs, tour_grid, hours_table)해서 메인·서브 재사용.
2. `/clinic?tab=` 쿼리로 초기 활성 탭 지정. GNB의 클리닉 3개 메뉴 연결.
3. 서브페이지 공통 상단: 페이지 제목 띠(딥 배경, H1) + 브레드크럼.
4. 404 페이지.

## Phase 3 — 지도 + 문의
1. 카카오맵: `location.html` + 메인 섹션 10. `CLINIC_LAT/LNG` 환경변수. 마커 + 병원명 인포윈도우 + "길찾기" 버튼(카카오맵 앱/웹 링크 `https://map.kakao.com/link/to/{name},{lat},{lng}`).
2. 문의 폼 (`/location` 하단 + 모바일 바 "예약" 버튼 클릭 시 모달): 이름·연락처·증상 부위(select: 목/허리/무릎/어깨/기타)·내용·개인정보 동의 체크.
3. `POST /api/inquiry` → `inquiries` 테이블 (id, name, phone, part, message, created_at, ip). 서버측 검증, 간단 rate limit(IP당 5분 3회), honeypot 필드.
4. 관리자 `/admin/inquiries` — 기본 Basic Auth, 최신순 테이블, CSV 다운로드. (둥지한의원 admin 패턴 재사용)
5. 문의 접수 시 병원 이메일 발송(SMTP, 선택).

## Phase 4 — SEO·배포
1. 페이지별 `<title>` `<meta description>` OG 태그. 병원명 + "정형외과" + 지역명 조합.
2. `/sitemap.xml` `/robots.txt` 동적 생성. 네이버 서치어드바이저 소유확인 메타 자리 `config.NAVER_SITE_VERIFICATION`.
3. JSON-LD `MedicalClinic` 스키마 (이름, 주소, 전화, 진료시간, 지도좌표).
4. 이미지 lazy loading, webp 변환 스크립트, 폰트 preload.
5. `deploy/`: gunicorn systemd unit, nginx conf(정적 캐시 30d, gzip), `.env` 예시. Cafe24 배포 순서 README.

## DB 스키마 (Phase 3)
```sql
CREATE TABLE inquiries (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(50) NOT NULL,
  phone VARCHAR(20) NOT NULL,
  part VARCHAR(20),
  message TEXT,
  ip VARCHAR(45),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  is_read TINYINT(1) DEFAULT 0
) CHARACTER SET utf8mb4;
```
